# chand 1.7.1 — نسخه ۲۹

ترتیب منابع دلار: **Hansha → آلان‌چند → TGJU**. پس از نخستین قیمت معتبر، منابع بعدی فراخوانی نمی‌شوند. شکست همه منابع، نرخ ذخیره‌شده و آخرین تغییر واقعی را حفظ می‌کند.

آلان‌چند: ردیف دقیق دلار آمریکا و ستون فروش صفحه اصلی، با واحد تومان؛ مسیر دوم همان سایت، Product/Offer صفحه اختصاصی USD با واحد صریح IRR یا IRT است. قیمت خرید، تتر، دلار استانبول و اعداد تاریخچه جایگزین دلار آمریکا نمی‌شوند.

نشانی‌های وب هنگام اجرا از کاتالوگ مبهم بازیابی می‌شوند. R8، کوچک‌سازی منابع، پنهان‌سازی نمادهای نیتیو و کنترل‌های قبلی حفظ شده‌اند. قفل امضای مستقلی در کد نیتیو اضافه شده است تا تغییر pin کاتلین به‌تنهایی برای عبور از محافظت کافی نباشد. نشانی‌های عمومی و کد سمت کاربر همچنان قابل مهندسی معکوس‌اند؛ حفاظت مطلق ادعا نمی‌شود.

CI اجرای صحیح APK اصلی و توقف دو نسخه کنترل‌شده دستکاری‌شده را روی شبیه‌ساز می‌سنجد: امضای جدید، و امضای جدید همراه با تغییر pin کاتلین. کلید آزمایشی این آزمون‌ها منتشر نمی‌شود. این آزمون جای بررسی روی گوشی واقعی یا تضمین مقاومت مقابل همه ابزارها را نمی‌گیرد.

آیکون، فونت مشترک برنامه و ویجت‌ها، تقویم شمسی، ظاهر MIUI/Samsung و زمان‌بندی ۱۵ دقیقه‌ای نسخه ۱٫۷٫۰ حفظ شده‌اند. ساخت hardened همچنان به هویت امضای همان محیط وابسته است؛ به‌روزرسانی نصب قبلی نیازمند همان کلید امضاست.
